# VK Assistant 3.3 — interface specification

## Visual direction
A modern, calm Material 3 Android interface. The first implementation uses a dark navy surface with blue accents; light and dark color schemes are supported by the theme layer.

## Main navigation
- Главная — monitoring state, connection summary, start/stop controls, activity summary.
- Сообщества — community list, per-community monitoring and explicit auto-publish consent.
- ИИ-помощник — generation settings and draft review. Drafts are never published automatically by the UI.
- История — chronological event feed.
- Настройки — VK/Telegram/AI connections, filters, quiet hours, appearance, security information.

## Safety and interaction rules
- Auto-publishing is visibly off by default.
- Enabling it must be an explicit per-community action with a clear confirmation.
- Show a persistent monitoring state and an obvious stop action.
- Never display secret values in plain text by default.
- Keep the existing FLAG_SECURE behavior.
- Do not imply background monitoring is guaranteed while Android restricts background execution.

## Implementation status
The Compose screen scaffold is a UI prototype. It is not wired to the existing 3.1 service/preferences yet. The secure 3.1 source project must be integrated before a complete APK can be built.
