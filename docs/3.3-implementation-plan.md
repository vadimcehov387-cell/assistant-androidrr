# VK Assistant 3.3 implementation plan

## Baseline
Use the secure 3.1 source archive as the baseline. Do not base the update on the older 3.0 phone build.

## Work packages
1. **Project integration** — place the complete 3.1 Android project in this repository and verify Gradle/JDK compatibility.
2. **Versioning** — set Android versionName to 3.3.0 and increment versionCode only after the project files are integrated.
3. **UI refresh** — modernize the interface while preserving the existing monitoring, preferences, and API behavior.
4. **AI drafts** — clearly distinguish drafts from published comments; invalid or failed AI output must never trigger auto-publishing.
5. **Community safety** — auto-publishing remains disabled by default, with per-community opt-in and rate limits.
6. **Security review** — verify encrypted preference migration, TLS-only endpoints, redirect handling, token-safe request bodies, and no secret logging.
7. **Validation** — run Gradle checks, build a debug APK, and test install/monitor/stop flows on Android.

## Release gate
Do not call 3.3 complete until source integration, a successful build, and basic device tests have been recorded. Do not commit API keys, tokens, signing keys, or generated secrets.
