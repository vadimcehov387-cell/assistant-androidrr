# VK Assistant 3.3 — план интеграции

## Исходная база

Используем **VKAssistantAndroid_3.0_source.zip** — это доступный исходный Android-проект. Версии 3.1 у пользователя нет, поэтому она не является требованием и не должна упоминаться как обязательная база.

Исходники 3.0 пока находятся в архиве переписки, а не в GitHub-ветке. Ветка `release/3.3` уже содержит подготовленные файлы нового Compose-интерфейса, но пока не содержит полного Android-проекта.

## Этап 1. Перенос проекта 3.0

- Добавить в `release/3.3` Gradle-файлы, манифест, ресурсы и исходники из `VKAssistantAndroid_3.0_source.zip`.
- Сохранить пакет `ru.vkassistant.mobile` и существующие идентификаторы приложения.
- Не менять поведение VK API, AI-черновиков, настроек и фонового мониторинга на этапе переноса.
- Не переносить APK и секреты в репозиторий.

**Критерий готовности:** структура проекта открывается как Android-проект и Gradle видит модуль `app`.

## Этап 2. Подключение нового интерфейса

- Подключить Jetpack Compose, Compose Material 3 и Activity Compose совместимых версий.
- Настроить Compose в `app/build.gradle`.
- Подключить `AssistantTheme.kt` и `MainScreen.kt` к существующей `MainActivity`.
- Перенести реальные действия старого экрана в callbacks нового интерфейса: запуск/остановка мониторинга, управление сообществами, AI-настройки, история и настройки.
- Не оставлять кнопки-заглушки там, где пользователь ожидает реальное действие.
- Сохранить системную защиту экрана и существующие разрешения.

**Критерий готовности:** приложение открывает новый интерфейс, а основные действия вызывают прежнюю рабочую логику.

## Этап 3. Обновление версии

- Установить `versionName = "3.3.0"`.
- Увеличить `versionCode` относительно исходного проекта.
- Обновить название и описание версии в README и CHANGELOG.

## Этап 4. Проверка безопасности и совместимости

- Проверить хранение токенов и миграцию настроек.
- Убедиться, что секреты не попадают в URL, логи и Git.
- Проверить HTTPS, обработку ошибок VK/AI и поведение при отсутствии сети.
- Сохранить безопасные ограничения автопубликации: выключена по умолчанию, отдельное включение для сообщества, лимиты частоты.
- Убедиться, что сбой ИИ или невалидный ответ не приводит к публикации.

## Этап 5. Сборка и тестирование

- Выполнить Gradle sync и сборку debug APK.
- Исправить ошибки Kotlin/Gradle.
- Проверить запуск приложения, сохранение настроек, список сообществ, старт/стоп мониторинга и экран истории.
- Отдельно проверить поведение на Android при сворачивании приложения и ограничениях фоновой работы.

## Что нужно для продолжения переноса

Архив `VKAssistantAndroid_3.0_source.zip` доступен в этой переписке, но GitHub-коннектор не может напрямую взять локальный файл из переписки и загрузить его бинарно. Чтобы перенести исходники в репозиторий без ручного копирования десятков тысяч символов, загрузите этот ZIP в ветку `release/3.3` через GitHub: **Add file → Upload files → Commit changes**. После этого можно распаковать его в структуру проекта, подключить Compose и проверить сборку.
